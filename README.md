# Homework 4: OOP in Python

Учебный проект по объектно-ориентированному программированию. Реализована система товаров и категорий с наследованием и базовым покрытием тестами.

## Структура проекта

- `src/product.py` — базовый класс `Product` с общей логикой.
- `src/smartphone.py`, `src/lawn_grass.py` — дочерние классы с уникальными атрибутами.
- `src/category.py` — управление категориями и подсчёт товаров.


## Реализованная функциональность

В рамках задания реализованы следующие возможности:

*   **Иерархия классов:** базовый класс `Product` и дочерние классы (`Smartphone`, `LawnGrass`) с уникальными атрибутами.
*   **Управление категориями:** класс `Category` для группировки товаров, подсчёта количества и валидации типов при добавлении.
*   **Валидация данных:** проверки на корректность типов (например, исключение `TypeError` при передаче неверного объекта) и контроль значений.
*   **Тестирование:** полный набор тестов на `pytest`, включая проверку уникальной логики наследников и обработку исключений.
*   **Работа с данными:** предусмотрена структура для хранения данных (папка `data`) и вспомогательные утилиты (`utils.py`).


## Качество кода и инструменты контроля

Код проекта полностью соответствует стандарту **PEP 8**. Для поддержания чистоты и единообразия кодовой базы используются следующие классические инструменты:

*   **Black** — автоматический форматтер кода. Приводит стиль кода к единому виду, устраняя споры о пробелах и переносах строк.
*   **Flake8** — линтер для поиска стилистических ошибок и нарушений PEP 8, а также простых логических багов (неиспользуемые импорты, переменные и т.д.).
*   **Mypy** — статический анализатор типов. Проверяет корректность аннотаций типов и помогает избежать ошибок, связанных с передачей данных неверного типа.
*   **Isort** — утилита для автоматической сортировки и группировки импортов в файлах.

Эти инструменты интегрированы в рабочий процесс и запускаются перед каждым коммитом для гарантии высокого качества кода.


## Стек технологий

- Python 3.12
- Poetry (управление зависимостями)
- pytest + pytest-cov (тестирование и анализ покрытия)
- unittest.mock (мокирование)

## Быстрый старт


**Запуск файла main.py:**
    Файл `src/main.py` запускается без ошибок и демонстрирует работу основных классов:
```bash
poetry run python -m src.main
```


**Проверка качества кода (линтинг и форматирование):**
```bash
    # Проверка типов (mypy)
    poetry run mypy src
    
    # Проверка стиля и ошибок (flake8)
    poetry run flake8 src
    
    # Проверка и сортировка импортов (isort)
    poetry run isort src --check
    
    # Проверка форматирования (black)
    poetry run black src --check
    ```
